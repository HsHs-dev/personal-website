# Reusable doors

Import `DoorEntrance`, `DoorGallery`, or `Door` from this folder. Styles and local font assets are included automatically.

See **[the setup guide](../../../docs/DOOR_COMPONENTS.md)** for navigation callbacks, examples, props and maintenance. Run the project and open `/door-preview.html` to inspect the standalone preview.

The guide is at the repository root's `docs/DOOR_COMPONENTS.md` (three levels above this directory).
